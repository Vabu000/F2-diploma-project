# ВСТУП

## Актуальність теми
Більшість комерційних систем обліку для малого бізнесу базуються на статичному відстеженні кількісних залишків, що не дозволяє ефективно контролювати швидкопсувну продукцію. Відсутність автоматизованого контролю за динамічним життєвим циклом товарів при зміні їхнього фізичного стану призводить до неточного розрахунку фінансових втрат, ускладнює дотримання санітарних норм та знижує маржинальність. Впровадження модульного моноліту з транзакційним списанням дозволить ліквідувати ці архітектурні недоліки.

## Об'єкт дослідження
Процес управління ресурсами, фінансовим обліком та відстеженням життєвого циклу товарів у межах підприємств ресторанного господарства.

## Предмет дослідження
Методи динамічного моделювання станів (State Machine), алгоритми пріоритетного списання FEFO, а також архітектурні патерни побудови веб-орієнтованих систем обліку на базі React та Node.js.

## Мета роботи
Розробка веб-орієнтованої інформаційної системи управління ресурсами бізнесу з використанням моделі State Machine та принципу FEFO для оптимізації автоматизованого обліку та динамічного відстеження життєвого циклу товарів на прикладі кав'ярні.

## Завдання проєкту
1. Проаналізувати існуючі програмні рішення для управління ресурсами кав'ярень та виявити їхні архітектурні обмеження.
2. Обґрунтувати вибір технологічного стеку для реалізації транзакційного складського обліку та динамічної зміни станів.
3. Спроєктувати архітектуру бази даних та діаграми взаємодії компонентів системи за допомогою UML.
4. Розробити алгоритми автоматизованого списання (FEFO) та перемикання таймерів життєвого циклу (State Machine).
5. Спроєктувати та реалізувати інтерактивний користувацький інтерфейс для управління вітриною та складом.
6. Виконати інструментальний аудит та тестування розробленої системи.
7. Оформити пояснювальну записку та підготувати результати до науково-практичної апробації.
