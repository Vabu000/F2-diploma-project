# Thesis Proposal

## Попередня робоча назва проєкту
**UA:** Веб-орієнтована інформаційна система управління ресурсами бізнесу з динамічним відстеженням життєвого циклу товарів та автоматизованим обліком на прикладі кав'ярні.
**EN:** Web-based business resource management information system with dynamic product lifecycle tracking and automated accounting based on a coffee shop.

## Актуальність та проблематика
Існуючі комерційні системи обліку для малого бізнесу переважно базуються на статичному відстеженні кількісних залишків. Проблема полягає у відсутності автоматизованого контролю за динамічним життєвим циклом швидкопсувної продукції при зміні її фізичного стану (наприклад, розморожування напівфабрикатів та їх експозиція на вітрині). Це призводить до неточного розрахунку фінансових втрат та ускладнює дотримання санітарних норм.

## Сформована ідея продукту (Нове у проєкті)
Запропоновано реалізацію системи управління ресурсами (ERP-модуля), базою якої є динамічна модель станів продуктів (State Machine) у поєднанні з алгоритмом пріоритетного списання FEFO (First Expired, First Out). На відміну від існуючих комерційних аналогів, система автоматично ініціює зміну життєвого циклу об'єкта при зміні його статусу (наприклад, із FROZEN у DISPLAY) з відповідним перерахунком таймерів придатності. Архітектурно проєкт реалізується як модульний моноліт із розділенням бізнес-логіки складського обліку та управління вітриною.

## Детальний опис функціоналу (Core Features)
1. **Динамічний трекінг станів (State Machine):** Автоматичне перемикання таймерів життєвого циклу товарів залежно від їхнього поточного статусу в системі.
2. **Смарт-списання продукції:** Автоматична генерація актів списання по собівартості при вичерпанні розрахованого таймеру вітрини (наприклад, 48 годин для розморожених десертів).
3. **Композитне списання за технологічними картами:** Транзакційне списання інгредієнтів зі складу (кава, молоко, пакування) при реєстрації продажу складеної позиції.
4. **Алгоритмічна оптимізація FEFO:** Автоматизована видача рекомендацій персоналу щодо пріоритетних партій товару для використання на основі найближчого терміну придатності.
5. **Ролевий доступ та автентифікація:** Розмежування прав між адміністратором (бухгалтерія/склад) та баристою (вітрина/продажі).
6. **Інтерактивні UI-дашборди:** Оптимізовані користувацькі інтерфейси для швидкого переведення станів товарів без перевантажених табличних виглядів.

## Попередній інструментарій та технологічний стек
* **Frontend:** React, TypeScript, гібридний рендеринг, система компонентів на базі прототипів із Figma.
* **Backend:** Node.js (NestJS/Express) — реалізація REST API та транзакційної логіки.
* **База даних:** PostgreSQL (реляційна структура для фінансових транзакцій та технологічних карт).
* **DevOps / Інструментарій:** Git (Docs-as-Code), Docker (контейнеризація БД та бекенду), ESLint/Prettier.
